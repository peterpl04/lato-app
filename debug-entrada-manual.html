🔍 Debug - Entrada Manual

🐛 Problema Reportado

Sintoma: Não consegue adicionar entrada manualmente quando clica no item e vai para tela específica.

Possíveis Causas:

  • Modal de movimento não está abrindo
  • Campos não estão sendo preenchidos corretamente
  • Validação está bloqueando entradas
  • Erro no processamento da API
  • Event listener não está funcionando

🔬 Passos para Debug

1. Teste Básico do Botão

  1. Abra o sistema de estoque
  2. Clique em qualquer item para ir aos detalhes
  3. Procure o botão "↓ Entrada" na seção de ações
  4. Clique no botão
  5. Resultado esperado: Modal deve abrir com título "↓ Registrar Entrada"

2. Teste dos Campos

  1. No modal de entrada aberto:
  2. Verifique se data está preenchida automaticamente (hoje)
  3. Verifique se campo "Endereço/Local de Saída" está OCULTO (só para saídas)
  4. Digite uma quantidade (ex: 10)
  5. Clique em "Registrar Movimentação"

3. Verificar Console

  1. Abra DevTools (F12)
  2. Vá para aba Console
  3. Tente adicionar uma entrada
  4. Procure por erros em vermelho
  5. Verifique se há logs de "Erro ao registrar movimento"

4. Verificar Network

  1. Na aba Network do DevTools
  2. Tente adicionar entrada
  3. Procure por requisições para /movements
  4. Verifique status da resposta (200 = OK, 4xx/5xx = erro)

🎯 Validação Específica

Código atual para validação:

// Só valida endereço para SAÍDAS, não para entradas
if (type === 'saida' && !address) {
    // Bloqueia apenas saídas sem endereço
    return;
}

✅ Para ENTRADAS: Não deve haver validação de endereço

❌ Para SAÍDAS: Endereço é obrigatório

🛠️ Possível Solução

Se identificar onde está o problema, aplicar uma das correções:

  • Modal não abre: Verificar event listeners
  • Campos vazios: Verificar setDefaultDate()
  • Validação bloqueia: Verificar lógica de entrada vs saída
  • API error: Verificar backend/conexão
