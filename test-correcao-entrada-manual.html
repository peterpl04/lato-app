🔧 Teste - Correção Entrada Manual

🐛 Problema Identificado

Causa raiz: Campo de endereço com atributo required HTML5 estava bloqueando entradas mesmo quando oculto.

Comportamento:

  • ❌ Para entradas: Campo oculto mas ainda com required → Validação HTML5 bloqueia submit
  • ✅ Para saídas: Campo visível com required → Validação funciona corretamente

✅ Correção Aplicada

1. Remoção do atributo `required` estático

Campo de endereço não tem mais required fixo no HTML.

2. Controle dinâmico via JavaScript

if (type === 'entrada') {
    // Campo oculto e SEM required
    exitAddressGroup.classList.add('is-hidden');
    movementAddress.removeAttribute('required');
} else {
    // Campo visível e COM required  
    exitAddressGroup.classList.remove('is-hidden');
    movementAddress.setAttribute('required', 'required');
}

3. Validação JavaScript mantida

Validação customizada para saídas continua funcionando normalmente.
